# Branding — ITOM Solutions

LabBuilder is branded **ITOM Solutions** ([www.itomsol.com](https://www.itomsol.com)), using the same mark and colours as the
IT Portal product branding:

| File | Use |
|------|-----|
| `itom-mark.svg` | Source mark (lime `#C6F277` rounded square, ink `#111A24` "i"), from the itomsol.com favicon |
| `itom-mark.png` | 256 px render, embedded in the exe and shown in the wizard side panel |
| `labbuilder.ico` | Exe/window icon (16–64 px) |

Colours are defined in `installer/src/Brand.cs`. `installer/build.ps1` fails if a file is missing.
